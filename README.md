# Monthly Expense Tracker

## Overview

I am building toward a career in software engineering, with a particular interest in reliable backend applications. I want to strengthen my ability to model data, validate user input, and organize a program into focused classes.

Monthly Expense Tracker is a Java console application for recording expenses by description, amount, category, and date. It lets a user review and remove entries, set a monthly budget, and view current-month totals by category.

The program saves its records and budget in a local CSV file so information remains available after the application closes. This project gives me a practical way to learn Java syntax, collections, object-oriented design, and file handling.
